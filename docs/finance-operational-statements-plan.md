# 운영 재무제표·월마감 원장 동결 기획

## 1. 기획

- 2026 손익계산서와 재무상태표는 승인된 2026 개시잔액과 ERP에서 `POSTED` 상태가 된 통제 분개·지급 전표만으로 만든다.
- Clobe 원문, 세금계산서 통계, 검증 스테이징, 작성·결재 중 전표는 재무제표에 직접 합산하지 않는다.
- 손익계산서는 조회기간 수익·비용 움직임으로, 재무상태표는 조회종료일 계정 잔액으로 계산한다.
- 개시잔액 미승인, 금액이 있는 미분류 계정, 총계정원장 차대변 불일치, `자산 = 부채 + 자본 + 당기손익` 불일치가 있으면 `DRAFT`로 표시한다.

## 2. 평가

- 기존 총계정원장은 승인 전 2025 결산 참고값도 조회할 수 있었으므로, 같은 숫자를 곧바로 공식 재무제표로 오인할 위험이 있었다.
- 세금계산서 공급가액은 증빙 통계이며 전기 원장과 범위가 다르므로 손익 원천으로 사용할 수 없다.
- 월마감 스냅샷에는 업무·통제만 저장되어 개시잔액 버전이나 제출 시점 원장 자체를 사후 재현할 증거가 부족했다.

## 3. 개선된 기획

- 화면에서 공식/검토용 상태와 공식화되지 못한 이유를 함께 표시한다.
- 계정 분류는 활성 재무 마스터를 우선하고, 승인 개시잔액 분류와 보수적 코드 규칙을 순서대로 사용한다. 금액이 있는 `OTHER` 계정은 공식화를 차단한다.
- 월마감 제출 시 개시잔액 세트 ID·원천 SHA-256, 전기 행 수, 개시/당기/기말 차대변 합계·차이, 재무제표 요약, 정렬된 전기행 SHA-256을 동결한다.
- 월마감 제출 직전에 원장을 다시 계산하여 승인·균형 상태가 바뀌었으면 제출을 거부한다.

## 4. 구축 범위

- 총계정원장 API: 운영 손익계산서·재무상태표 및 품질 상태 반환.
- 총계정원장 화면: 핵심 합계, 계정별 구성, 공식화 차단 사유 표시.
- 월마감 통제: 승인된 개시잔액과 총계정원장·회계등식 균형 자동 점검.
- 월마감 승인 스냅샷: 원장 계보와 SHA-256 해시 동결.

## 5. 검증 기준

- 수익·비용 예제의 당기순이익과 자산·부채·자본·당기손익 회계등식이 일치한다.
- 개시잔액 미승인 또는 미분류 계정이 있으면 `DRAFT`다.
- 월마감 소스에 개시잔액 ID·체크섬, `ledgerHash`, 원장 합계와 재무제표 요약이 포함된다.
- 기존 총계정원장 CSV와 전기 원천 제한이 유지된다.
- 전체 빌드와 회계·업무원장 회귀 테스트를 통과한다.
