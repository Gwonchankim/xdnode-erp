# HR 통계·리포트 기획

## 목적

- 인사기록, 채용, 급여, 성과평가, 교육 원장을 기간 기준으로 집계해 의사결정 자료로 제공한다.
- 화면에 고정된 임의 숫자를 사용하지 않고 각 지표의 산식과 원천을 명확히 표시한다.
- 개인 이름·연락처·생년월일 없이 집계 데이터만 노출한다.

## 주요 지표

- 인원: 기간 말 재직자, 입사자, 퇴직자, 월말 인원 추이, 조직별 인원
- 이직률: 기간 중 퇴직자 ÷ 기간 시작·종료 평균 재직자 × 100
- 채용: 지원자 수, 지원경로, 단계별 퍼널, 입사 확정 전환율, 평균 채용기간
- 인건비: 월별 지급총액·공제총액·기록상 지급액, 조직별 지급총액
- 성과: 최종 확정된 평가의 등급 분포와 평균 점수
- 교육: 대상자, 수료·면제, 증빙 검토 대기, 미이수, 과정별 이수율

## 권한과 개인정보

- HR 조회 권한 사용자는 개인 식별자가 없는 인원·채용·교육 집계를 확인한다.
- 급여와 성과평가 집계는 HR 관리자 또는 최고관리자에게만 제공한다.
- CSV에도 개인 이름, 사번, 이메일, 연락처, 생년월일을 포함하지 않는다.
- 저장 리포트는 생성 당시 집계값과 산식을 JSON 스냅샷으로 보존하고 일반 수정하지 않는다.

## 운영 흐름

1. 사용자가 시작일과 종료일을 선택한다.
2. 서버가 각 업무 원장에서 기간 조건에 맞는 집계와 데이터 품질 경고를 계산한다.
3. HR 관리자는 현재 집계를 버전형 리포트로 생성해 당시 수치를 고정한다.
4. 사용자는 동일한 집계 범위의 CSV를 내려받아 경영회의 자료로 사용한다.

## 평가 후 개선사항

- 재직자 수는 현재 상태 단순 합계가 아니라 입사일·퇴직일을 이용한 기간 말 스냅샷으로 계산한다.
- 채용기간은 입사 확정된 지원자의 지원일에서 입사예정일까지의 일수만 사용한다.
- 확정되지 않은 성과평가는 등급 분포에 포함하지 않는다.
- 교육의 직원 제출은 수료가 아니라 증빙 검토 대기로 별도 표시한다.
- 인건비 원장이 없는 기간은 0원으로 오해하지 않도록 데이터 없음 상태를 표시한다.
- 계산에 필요한 입사일·퇴직일이 누락된 경우 데이터 품질 경고에 포함한다.
