# HR 녹음 서버 전사 통제 기획안

## 평가

- 직원 면담은 브라우저 `SpeechRecognition`이 있을 때만 실시간 전사가 되고, 지원자 면접 녹음은 파일 저장만 가능하다.
- 브라우저 전사는 지원 여부와 품질이 브라우저·운영체제에 따라 달라 재현할 수 없고, AI 결과와 사용자가 수정한 문장을 구분하지 않는다.
- 녹음 당사자 동의, 외부 AI 전송 확인, 모델·시도·실패·무료한도, 사용자 최종 검토를 증명할 원장이 없다.

## 개선된 설계

1. 녹음 원본은 기존 비공개 R2에 보존하고 전사 시점에만 서버가 읽는다.
2. 사용자가 녹음 당사자의 동의와 Cloudflare Workers AI 전송을 명시적으로 확인해야 전사를 시작한다.
3. 공식 한국어 ASR 모델 `@cf/openai/whisper-large-v3-turbo`와 VAD를 사용하며 모델명·시도 횟수·요청자·시각을 보존한다.
4. 10MB를 넘는 녹음은 임의 바이트 분할로 왜곡하지 않고 녹음을 나누어 저장하도록 안내한다.
5. AI 원문은 수정하지 않고 사용자 검토본을 별도 필드에 한 번 확정한다. 재전사는 새 시도로 남겨 과거 결과를 덮어쓰지 않는다.
6. 무료한도 초과, 시간초과, 원본 없음, 무음, 공급자 오류를 서로 다른 상태로 기록하고 안전하게 재시도한다.
7. 감사로그에는 전사 내용 자체가 아니라 대상, 모델, 단어 수, 시도, 검토 여부만 남긴다.

## 검증 기준

- 동의 없이 전사할 수 없다.
- HR 면담과 채용 면접 권한이 서로 분리된다.
- 실패한 시도와 완료된 AI 원문은 새 시도로 덮어쓰지 않는다.
- 사용자 확정 전사문과 AI 원문이 분리되어 조회된다.
- 무료한도 초과와 일반 실패가 화면에서 구분된다.
- 10MB 초과 파일은 공급자 전송 전에 차단된다.
