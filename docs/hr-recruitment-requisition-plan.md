# 채용요청·TO 관리 기획

## 평가

- 승인된 정원 부족과 지원자·채용 제안이 연결되지 않아 중복 충원과 초과 채용을 예방할 수 없다.
- 지원자 수는 확보 인원이 아니며, 채용 제안 수락으로 입사 예정 인사기록이 생성된 때만 정원에 반영해야 한다.
- 면접 직접 등록은 예외 절차로 유지하되, 정원을 사용하는 채용 제안은 승인된 TO의 잔여 좌석을 검증해야 한다.

## 통제 원칙

1. 최신 승인 인력계획의 조직별 충원 필요 인원 안에서만 TO를 만들 수 있다.
2. 작성 중·결재 중·모집 중 TO도 예약 좌석으로 보아 같은 부족분을 중복 기안하지 못한다.
3. TO는 작성, 결재 제출, 모집 중, 충원 완료 또는 사유를 남긴 초안 취소·조기 마감 순서로 진행한다.
4. 지원자는 하나의 TO에 선택적으로 연결한다. 예외 면접은 허용하지만 TO 없는 채용 제안은 별도 승인 흔적으로 남는다.
5. TO에 연결된 지원자의 채용 제안은 모집 중인 잔여 좌석과 소속 조직이 일치해야 한다.
6. 채용 제안 수락 시에만 충원 인원으로 계산하고, 목표 인원 도달 시 TO를 자동 완료한다.
7. 모든 생성·제출·마감과 결재 결과는 감사기록에 남긴다.

## 화면 산식

- 계획 부족 = 승인 정원 - (현재 재직 + 입사 예정 - 계획 퇴사)
- 예약 TO = 작성/결재/모집 중 TO의 요청 인원 - 이미 수락된 인원
- 추가 기안 가능 = 계획 부족 - 예약 TO
- TO 잔여 = 요청 인원 - 수락 완료 인원
